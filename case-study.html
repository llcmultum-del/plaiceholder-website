Case Study: Signal Engine

The first build. A sales prospecting agent for a software escrow company. Pilot in progress.

The project

A prospecting agent built in four days

Client: [Case Study Client], a software and IP escrow company.

An agency quoted $9,500 for 60 hours of custom development plus $1,500 for a month of support, over five weeks.

We built a working, packaged agent in four days. The client sets it up with four commands.

What it does

How the agent works

Pulls target companies from Apollo

Filtered by industry, size, and other criteria set in the discovery interview.

Researches recent news at half price

AI batch processing cuts the cost of researching hundreds of companies at once.

Throws out unverified links

Any news link the AI didn't actually find is discarded automatically before scoring.

Scores companies with editable rules

The scoring criteria — which signals matter most — are set by the client and can be changed without code.

Finds verified contacts within a credit cap

Apollo email reveals are capped per run, set in plain settings.

Writes to HubSpot and builds a rep dashboard

Score, tier, reasons, source links, and contacts go straight into HubSpot. Reps see a "who to call this week" dashboard.
